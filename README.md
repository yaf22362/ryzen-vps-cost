## Ryzen VPS 到底在买什么

买的是单线程速度——单核跑一个任务时能有多快。

VPS 行业的默认芯片是服务器级 CPU，比如 AMD EPYC 和 Intel Xeon。这类芯片堆的是核心数量，单核基础频率普遍只有 2.0–2.5 GHz，因为机房要在一台机器里塞下尽量多的租户。Ryzen 走的是另一条路：桌面旗舰 9950X 单核能加速到 5.7 GHz，PassMark 单线程成绩在 4,500 分上下，而服务器 EPYC 大多在 2,000–2,500 分一档。折算成体感，同一个单线程任务，耗时能省一半左右。

哪些任务在乎这个差距？各家产品页反复提到的其实是同一批：

- **游戏服**。Minecraft、Rust、Valheim 这类服务端的 tick 率是单线程瓶颈，频率越高，卡顿和“橡皮筋”越少。
- **PHP 和 WordPress**。每个页面请求跑在一个核心上，4–5 GHz 的核处理同样的请求就是比 2.4 GHz 快，TTFB 的差别肉眼可见。
- **Redis**。经典单线程服务，最快的 Redis 就是跑在最快那颗核上的 Redis。
- **交易机器人和实时 API**。下单路径每省一毫秒都有意义。
- **编译**。链接、转译这些环节吃单核，CI 快不快很大程度看频率。

反过来的情况也要说清楚：如果你的负载是多进程、高并发、能横向扩展的（比如网关、渲染农场），核心数量比单核频率重要，服务器级 CPU 反而划算。Cloudzy 自己的 FAQ 也写了这一条——负载能横向扩展的话，EPYC 更省钱。Ryzen VPS 是个特定场景的答案，这个场景覆盖的人不少，但它确实不是万能的。
